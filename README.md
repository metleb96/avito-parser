# Avito Parser & AI Search

## Описание
Проект для парсинга объявлений с Avito, их очистки, векторизации и умного поиска на основе семантической близости (используя Sentence Transformers). Включает графический интерфейс (GUI) на CustomTkinter.

## Функционал
1.  **Парсинг Avito**: Сбор данных (Название, Цена, Ссылка, Описание, Локация) с поддержкой "ленивого" скроллинга и обхода защиты (частично, требуется ручной ввод капчи при появлении).
2.  **Обработка данных**: Очистка текста от мусора, эмодзи и нормализация.
3.  **Векторизация**: Генерация векторных представлений (эмбеддингов) описаний товаров для семантического поиска.
4.  **Умный поиск**: Поиск по базе объявлений на естественном языке (например, "игровой пк для киберпанка" найдет мощные ПК, даже если в заголовке нет этих слов).
5.  **GUI**: Удобный интерфейс для всех этапов работы.

## Установка

1.  Клонируйте репозиторий:
    ```bash
    git clone https://github.com/ваш-аккаунт/avito-parser.git
    cd avito-parser
    ```

2.  Создайте виртуальное окружение (рекомендуется):
    ```bash
    mkvirtualenv avito-parser 
    # или
    python -m venv venv
    venv\Scripts\activate
    ```

3.  Установите зависимости:
    ```bash
    pip install -r requirements.txt
    ```

## Использование

Запустите графический интерфейс:
```bash
python gui.py
```
Или используйте `start.bat` для быстрого запуска в Windows.

### Вкладки
-   **Парсер**: Введите URL категории Avito, количество страниц и запустите сбор данных.
-   **Обработка**: Запустите очистку данных, затем векторизацию.
-   **Поиск**: Введите запрос для поиска по собранной базе.
-   **Данные**: Просмотр собранных CSV файлов.

## Требования
-   Python 3.8+
-   Google Chrome (для `undetected-chromedriver`)

## Важно
Этот проект предназначен только для образовательных целей. Автоматический сбор данных может нарушать правила использования Avito. Используйте с осторожностью.
